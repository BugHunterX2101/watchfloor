# ADR-001: Stateless MCP on 2025-11-25

- **Status:** Accepted
- **Source:** [DESIGN.md §26](../DESIGN.md#26-architecture-decision-records), copied verbatim. A change to this decision gets a new ADR; this file is never rewritten (TECHNICAL.md §20.5).

## Context

Alexa+ supports 2025-11-25. Lambda instances are ephemeral.

## Decision

SDK Streamable HTTP with `stateless_http=True` and `json_response=True`; no session IDs; state lives in explicit handles (job IDs, tokens).

## Alternatives

Stateful sessions with sticky routing (incompatible with Lambda scaling); 2026-07-28 (not supported by Alexa+).

## Consequences

No server-initiated requests (no elicitation or sampling), so confirmations use two tools (ADR-003). The 2026-07-28 upgrade path stays simple.
